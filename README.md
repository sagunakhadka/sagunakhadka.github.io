# Saguna Khadka — IT & Security Portfolio

A modern, responsive personal portfolio website for **Saguna Khadka**, an IT professional based in Maryland, USA, with a focus on networking, cybersecurity, cloud technologies, Linux, SQL, and hardware troubleshooting.

The website uses a calm, minimal visual style with responsive layouts, smooth animations, dark/light themes, certification filtering, and a simple professional presentation.

## 🎨 Design System

The website uses a warm, minimal visual language in light mode and a muted green-toned dark theme.

### Light Theme

```text
Background: #f6f2ec
Foreground: #1d1a17
Muted:      #7a736b
Border:     #ded7cc
Accent:     #9a6b4f
Card:       #fbf8f3
```

### Dark Theme

```text
Background: #111815
Foreground: #edf3ef
Muted:      #9aa9a3
Border:     #29352f
Accent:     #91b6a8
Card:       #17201c
```

The theme automatically responds to the user's system preference and can also be manually toggled from the navigation bar.

## 🌗 Theme System

The website supports:

- Automatic system theme detection
- Manual light/dark switching
- Smooth color transitions
- Dark mode optimized for readability
- Persistent visual consistency across sections

Theme switching is handled using the `data-theme` attribute on the root HTML element.

## ⚡ Animations & Interactions

The website includes several lightweight animations.

### Hero Animation

The main heading enters the screen with a vertical reveal animation.

### Scroll Reveal

Sections fade and slide upward as they enter the viewport using the `IntersectionObserver` API.

### Statistics Counter

Statistics animate from `0` to their final values when they become visible.

### Certification Filtering

Certification cards can be filtered by:

- All
- Networking
- Cloud
- Security
- Tools

### Scroll Progress

A thin progress bar at the top of the page indicates how far the visitor has scrolled.

### Theme Button

The theme toggle rotates when hovered and switches between light and dark appearances.

## ♿ Accessibility

The website includes several accessibility considerations:

- Semantic HTML structure
- Accessible theme toggle label
- Reduced-motion support
- Responsive typography
- Sufficient visual contrast
- Keyboard-friendly buttons and links
- `rel="noopener"` for external links opened in new tabs

Users who have enabled reduced motion at the operating-system level will have most animations disabled automatically.
